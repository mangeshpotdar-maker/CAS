# Installation Instructions

## Prerequisites
- Python 3.9+ (64-bit)
- pip package manager

## Automated Installation
Run `INSTALL.bat` in Windows or execute:
```bash
pip install -r requirements.txt
```

## Requirements (`requirements.txt`)
- streamlit >= 1.28.0
- pandas >= 2.0.0
- numpy >= 1.24.0
- plotly >= 5.15.0
- scipy >= 1.10.0
- pytest >= 7.0.0
